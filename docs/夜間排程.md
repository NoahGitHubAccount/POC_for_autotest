# 夜間排程 SOP

> 本文件說明如何設定 Windows 工作排程器（Task Scheduler）讓夜間自動化流程每晚自動執行。

---

## 架構概覽

```
nightly_run.ps1
  ├── Step 1  gen_missing_specs.py   → reports/<run_id>/gap_specs.txt
  ├── Step 2  gen_missing_tests.py   → reports/<run_id>/gap_tests.txt
  ├── Step 3  Warm Login             → .auth/admin.json 刷新
  └── Step 4  Full Test Suite        → reports/<run_id>/ + docx/
                                        reports/nightly_latest.txt
```

R2.1 / R2.2（gap 偵測）只產出報告清單，**不自動生成 spec/test**。  
隔天早上由人工（或排程的 AI session）依清單補齊。

## 快速驗證（先手動跑一次）

```powershell
# 在專案根目錄執行
$env:PYTHONUTF8 = "1"
.\scripts\nightly_run.ps1 -env_name test -shot on-failure
```

確認 `reports/nightly_latest.txt` 有寫入後，再設定排程器。

## Windows 工作排程器設定

### 方法 A：PowerShell 一鍵建立

以**系統管理員**身份開啟 PowerShell，執行：

```powershell
$projectRoot = "<本 repo 的絕對路徑>"   # 例：D:\repos\POC_for_autotest
$triggerTime = "02:00"   # 每天 02:00 觸發

$action = New-ScheduledTaskAction `
    -Execute "powershell.exe" `
    -Argument "-NonInteractive -ExecutionPolicy Bypass -File `"$projectRoot\scripts\nightly_run.ps1`" -env_name test -shot on-failure" `
    -WorkingDirectory $projectRoot

$trigger = New-ScheduledTaskTrigger -Daily -At $triggerTime

$settings = New-ScheduledTaskSettingsSet `
    -ExecutionTimeLimit (New-TimeSpan -Hours 2) `
    -StartWhenAvailable `
    -RunOnlyIfNetworkAvailable

Register-ScheduledTask `
    -TaskName "POC_autotest_nightly" `
    -Action $action `
    -Trigger $trigger `
    -Settings $settings `
    -RunLevel Highest `
    -Description "POC 自動化測試夜間排程（env=test）"

Write-Host "排程工作已建立：POC_autotest_nightly"
```

### 方法 B：手動設定（Task Scheduler GUI）

1. 開啟「工作排程器」→「建立工作」
2. **一般** Tab：勾選「以最高權限執行」
3. **觸發程序** Tab：新增 → 每天 → 02:00
4. **動作** Tab：
   - 程式：`powershell.exe`
   - 引數：`-NonInteractive -ExecutionPolicy Bypass -File "<本 repo 的絕對路徑>\scripts\nightly_run.ps1" -env_name test -shot on-failure`
   - 起始位置：`<本 repo 的絕對路徑>`
5. **條件** Tab：勾選「只在網路可用時執行」
6. **設定** Tab：最長執行時間 2 小時；勾選「若工作未在排程時間執行，儘早執行」

## 排程管理指令

```powershell
# 查看排程工作
Get-ScheduledTask -TaskName "POC_autotest_nightly"

# 立即手動觸發（測試用）
Start-ScheduledTask -TaskName "POC_autotest_nightly"

# 停用排程
Disable-ScheduledTask -TaskName "POC_autotest_nightly"

# 刪除排程
Unregister-ScheduledTask -TaskName "POC_autotest_nightly" -Confirm:$false
```

## 多環境切替

| 目標 | 指令 |
|---|---|
| QA 環境（TEST）| `-env_name test` |
| 開發環境（DEV）| `-env_name dev` |
| 本機（LOCAL）| `-env_name local` |

不同環境對應不同設定檔：`config/config.test.yaml`、`config/config.dev.yaml`。  
建立方式：`Copy-Item config\config.example.yaml config\config.test.yaml`，再填入帳密。

## Lockfile 衝突迴避

`nightly_run.ps1` 執行前會檢查 `.nightly.lock`：
- 若存在：等待 15 分鐘，最多 3 次，仍存在則跳過本夜
- 若不存在：建立 lockfile，執行完成（或中途失敗）後自動刪除

**手動清除卡住的 lockfile：**

```powershell
Remove-Item .nightly.lock -Force
```

## 已知限制（目前版本）

| 限制 | 說明 |
|---|---|
| R2.1 SPEC 生成 | 只偵測 gap，**不自動呼叫 AI 生成**；需人工依 `gap_specs.txt` 補 |
| R2.2 TEST 生成 | 只偵測 gap，**不自動呼叫 AI 生成**；需人工依 `gap_tests.txt` 補 |
| Warm Login | 若 CAPTCHA 到期需人工介入（`mode: manual` 會卡住） |
| 通知 | 目前只寫入 `nightly_latest.txt`，無 email/Teams 通知 |
