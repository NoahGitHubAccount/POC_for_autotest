## 三、異常對照表

| 症狀 | 原因 | 處置 |
|---|---|---|
| 全部 401 | token 過期/貼錯 | 重取 token → 重跑 |
| T3 出現 400 | 報名規則「每人總上限」被改回 1（實測會自己跳回，原因不明） | **run bat 開跑前已自動重設為 0**（呼叫 `shared\ensure_limit.py`）；若仍 400，手動雙擊 `verify\fix_limit_and_test.bat` 修復後重跑 |
| Connection refused/timeout 大量 | 伺服器扛不住或網路 | 這本身就是壓測發現，記下發生時間點，報告會呈現 |
| 黑視窗閃退 | shared\token.txt 不存在 | 先做 token 步驟 |
| 找不到檔案/路徑 | 還沒跑 `_reorganize_once.bat` 整理目錄 | 先雙擊根目錄 `_reorganize_once.bat` 一次 |
